# ChefMaster

## Correr el proyecto
1. Guarda tu HTML de Canva como `public/index.html`
2. `npm install`
3. Crea la BD: `mysql -u root -p < schema.sql`
4. Copia `.env.example` a `.env` y pon tu password de MySQL
5. `npm run dev` → http://localhost:3000
